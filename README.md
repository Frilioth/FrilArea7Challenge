# Area 7 Challenge

A self-contained survival challenge mod for **7 Days to Die (V2.6)**.

You wake up inside a top-secret military research facility surrounded by lethal radiation. Your only goal: clear the facility, build an emergency transmitter, survive a blood moon horde, and escape before the facility kills you.

**Death is permanent.** If you die, your run is over.

## Features

- **4-phase challenge** tracked through the in-game challenge journal
- **Custom POI** — a fully built military research facility with sleeper volumes, loot, and progression
- **Tiered airdrop system** — your vehicle reward depends on how many magazines you've read
- **Themed zombie loot bags** — 8 types (Medical, Heavy, Hazmat, Books, Police, Researcher, Biker, VIP)
- **Custom crafting** — Emergency Transmitter, simplified Car Battery, craftable Acid, Engine recipe
- **Permadeath system** — lethal radiation zone prevents re-entry after death
- **Blood moon horde** — triggered when you deploy the transmitter
- **Mission debrief** — detailed HTML stats page generated after every run with kill breakdown, weapon usage, loot bag distribution, timeline, and game settings

## Installation

1. Download the latest release from the [Releases page](https://github.com/Frilioth/FrilArea7Challenge/releases)
2. Extract the zip file
3. Copy the `Mods` folder into your 7 Days to Die installation directory (merging with the existing Mods folder)
4. Launch the game with **EAC disabled** (Play without Easy Anti-Cheat)
5. Start a new game using the **Area 7 Challenge** world

## Recommended Settings

| Setting | Value |
|---|---|
| Air Drops | Disabled |
| Loot Respawn | 5 days |
| Biome Progression | Off |
