# Area 7 Challenge - Named Zombies
# Format: PlayerName=ZombieType
#
# Players who complete the challenge can have a zombie named after them.
#
# USE THE ENTITY CLASS NAME (zombieSoldier), not the display name (Soldier).
# The display name is TRANSLATED, so an English entry never matches for a German,
# French or Spanish player. Proof: Tycapanic's German debrief lists Soldat,
# Krankenschwester, Hausmeister, Laborant, Wartungstechniker. Only proper names
# survive translation (Darlene, Arlene, Joe, Moe, Yo, Boe, Marlene, Steve, Chuck,
# Tom Clark, Big Mama, Bowler, Tourist), and even those take a translated modifier:
# "Feral Steve" is "Wilder Steve". Class names are language-independent.
#
# Display names still work as a fallback (v3.0.42+) but only for English clients.
# Class names are case-sensitive and must match vanilla exactly. Several are NOT
# what you would guess: Lab Worker is zombieLab, Big Mama is zombieFemaleFat,
# Hazmat is zombieMaleHazmat, Businessman is zombieBusinessMan (capital M).
# The Key column of vanilla Data/Config/Localization.csv is the class name.
#
# Not all zombies of that type are renamed. The miss rate is 2/(names+2), so one
# name on a type shows on roughly 1 in 3, two names on 1 in 2, and so on. The pick
# is deterministic per zombie, so a given one always resolves the same way.
#
# Some common class names:
#   zombieSoldier  zombieJanitor  zombieNurse   zombieLab       zombieMaleHazmat
#   zombieUtilityWorker  zombieSpider  zombieArlene  zombieDarlene  zombieMarlene
#   zombieMoe  zombieJoe  zombieYo  zombieBoe  zombieBusinessMan  zombiePartyGirl
#   zombieFemaleFat  zombieMutated  zombieBurnt  zombieSteve  zombieTomClark
